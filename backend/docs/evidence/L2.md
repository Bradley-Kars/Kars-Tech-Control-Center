### How `core.paths` resolves vault and home in real mode

When no environment variables are set (`KTS_SANDBOX`, `KTS_VAULT`, `KTS_HOME` all unset), `core.paths._resolve_env()` returns real-mode paths:

- `vault_root()` → `/home/slayerbrk/Documents/KTS Records` (real vault)
- `home_root()` → `/home/slayerbrk/.ticketing` (real home)
- `config_dir()` → `/home/slayerbrk/.ticketing/config` (real config)
- `is_sandbox_mode()` → `False`

```
# Output: /home/slayerbrk/Documents/KTS Records /home/slayerbrk/.ticketing/config False
```
