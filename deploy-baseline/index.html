Deploy notes

Deployable artifacts live in this folder. Two supported paths:

Netlify — drag & drop

Drop this folder onto app.netlify.com/drop. netlify.toml sets publish = ".".

Cloudflare Pages — CLI 
$ npx wrangler pages deploy . --project-name kts-static-baseline

_headers in this folder is picked up automatically for cache & security headers.

Local preview 
$ python3 -m http.server 8080 --directory .

Then open http://127.0.0.1:8080. Dev/preview only — never production.
